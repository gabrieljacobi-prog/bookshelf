Import

Loads the old Bookshelf export into the new library. Nothing is written until you press Import, and running it again picks up where it stopped.

1 · Sign in

2 · Choose the CSV

The file stays on this device; only the cleaned books are sent to Firestore. Read status and the loan go to the private collection.

3 · Review the clean-up

4 · Try covers on a few books

Looks up 12 books and shows what each cover would become: copied (resized into Firestore) or link (the source doesn't allow copying, so we keep its URL). Nothing is written.

5 · Import

About 10 minutes for 409 books. Keep the screen on. Every book starts unverified.

6 · Retry missing covers

Looks again, one book at a time, for every book that has no cover yet. Only the cover is filled in. No CSV needed; just sign in. About 3–5 minutes.
